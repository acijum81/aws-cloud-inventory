# Changelog

## 1.0.0 - 2026-09-03

- Completed end-to-end AWS Cloud Inventory application.
- Added persistent inventory runs and errors.
- Added resource filtering, summary, CSV/JSON export and run comparison APIs.
- Added asynchronous API-triggered inventory execution with status tracking.
- Added accounts/regions discovery endpoints.
- Added React/Vite dashboard with inventory launch, run history, filters and exports.
- Added Docker Compose frontend + backend + PostgreSQL stack.
- Added production deployment guidance for OIDC/RBAC, SQS/EventBridge, ECS/EKS, Secrets Manager, ALB/WAF.
